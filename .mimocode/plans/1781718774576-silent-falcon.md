# Plan: Add ~/.bun/bin to PATH for all shells

## Context

The user wants `~/.bun/bin` in PATH across fish, nushell, and any other shell. No PATH management exists yet — `home.sessionPath` is not used anywhere in the repo.

## Approach

Edit **`home/linca/environment.nix`** — add `home.sessionPath` alongside the existing `home.sessionVariables`:

```nix
_: {
  home.sessionVariables = {
    EDITOR = "hx";
    VISUAL = "nvim";
  };

  home.sessionPath = [
    "$HOME/.bun/bin"
  ];
}
```

`home.sessionPath` is the home-manager mechanism that injects PATH entries into all configured shells (fish, nushell, bash, etc.) via PAM / profile scripts. No per-shell config needed.

## Files modified

- `home/linca/environment.nix` — add `home.sessionPath`
